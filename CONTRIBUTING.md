# Contributing to Lnr

Thank you for your interest in improving Lnr! While the plugin source code is closed-source, we welcome and appreciate community contributions in the following ways:

## 🐛 Bug Reports

Found a bug? Please [open an issue](https://github.com/ArtemTykhonuk/LnrPlugin-Public/issues/new?template=bug_report.md) and include:

1. **IDE and version** (e.g., IntelliJ IDEA 2025.3.4)
2. **Lnr plugin version** (e.g., 1.0.0)
3. **Operating system** (e.g., macOS 15, Windows 11)
4. **Steps to reproduce** — clear, numbered steps
5. **Expected behavior** vs. **actual behavior**
6. **Logs** (if applicable) — from `Help → Show Log in Finder/Explorer`

## 💡 Feature Requests

Have an idea? [Submit a feature request](https://github.com/ArtemTykhonuk/LnrPlugin-Public/issues/new?template=feature_request.md) and describe:

1. **The problem** you're trying to solve
2. **Your proposed solution**
3. **Alternatives** you've considered
4. **How it fits** with the existing plugin workflow

## 💬 Discussions

- Use [GitHub Issues](https://github.com/ArtemTykhonuk/LnrPlugin-Public/issues) for bug reports and feature requests
- Be respectful and constructive — see our [Code of Conduct](CODE_OF_CONDUCT.md)

## 📋 Issue Guidelines

- **Search first** — check if your issue or feature request already exists
- **One issue per report** — don't combine multiple bugs or features in one issue
- **Be specific** — vague reports are hard to act on
- **Include context** — screenshots, logs, and reproduction steps are incredibly helpful

## 🔒 Security Issues

If you discover a security vulnerability, please **do not** open a public issue. Instead, follow our [Security Policy](SECURITY.md).

---

Thank you for helping make Lnr better! 🙏
